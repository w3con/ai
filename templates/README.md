# Project AI templates

These templates provide optional starting points for project-local AI documentation and a Markdown knowledge base. Adapt the structure to the project rather than assuming every project needs every file.

## Included templates

- `kb-note.md`: a derivative knowledge-base note.
- `decisions-log.md`: a subject-specific decision history.
- `plan-card.md`: a task card with status, scope, acceptance criteria, checkpoints, and evidence sections.
- `kb-skeleton/`: a project knowledge-base scaffold and its agents and skills.

The templates preserve their field names and structural conventions for existing generators and parsers. They contain no project fixtures. The knowledge-base skeleton's executable commands live under `kb-skeleton/bin/` and are included as implementation files in the toolkit.
