Be concise. When the user corrects a misunderstanding, acknowledge it briefly and move on — do NOT re-explain the same distinction at length.

**Why:** in the 2026-05-28 planning session the user said "как я уже сказал" ("as I already said") after I repeated a multi-paragraph explanation of a point they'd already clarified. The repetition read as not listening.
**How to apply:** prefer short, direct answers and structured options over long prose. Trust that the user retains earlier context; reference it rather than restating it. Relates to [[feedback-scope-discipline]].
