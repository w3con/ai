# Memory — other projects' rules only, not a source for this one

This store is no longer where a rule is filed. A rule filed here reaches a session only when the store happens to surface it, never with certainty, while `~/Dev/ai/CLAUDE.md` and a project's own rules document reach every session and every raised agent whole. So nothing new is written here: a rule about the Validité application goes into `rules.md` in that repository, a rule about how Claude Code works everywhere goes into `~/Dev/ai/CLAUDE.md`, and everything about how to write goes into `../STYLE.md` and no other file.

What remains below is the standing knowledge of projects that carry no rules document of their own — the Validité website, the Pilier repositories, the business knowledge base and the correspondence work. Those files are left exactly as they are.

- [Reproduce the design, don't improvise](design-reproduce-not-improvise.md) — Validité website only: match the design files exactly, interview to full clarity first
- [Enter the knowledge base through its index](kb-entry-via-index.md) — Validité knowledge base only: start at `kb/_index.md`, never a blind grep
- [Pilier's internal KB is a private repo](feedback_pilier_private_kb.md) — Pilier only: internal reasoning, plans and decisions live in the private `pilier-org/cloud` repository, never in the public blockchain one
- [Verify repo vs live](feedback_pilier_verify_repo_vs_live.md) — Pilier only: before changing or auditing server config, diff the tracked file against the live host
- [Clone config verbatim](feedback-clone-config-verbatim.md) — deriving a new node or service config from an already-proven twin: copy the proven values byte for byte
- [Browser-verify: rAF sleeps in a background tab](browser-verify-raf-background-tab.md) — canvas and preview renders need the tab foregrounded via a screenshot
- [Approve the letter before writing it down](feedback-approve-letter-before-writing-it-down.md) — a letter lives in the chat message until Alex approves the text
- [Check both send routes](feedback-check-both-send-routes.md) — Validité only: a staged letter may already have gone from at@validite.eu or from the personal Gmail; open the message
